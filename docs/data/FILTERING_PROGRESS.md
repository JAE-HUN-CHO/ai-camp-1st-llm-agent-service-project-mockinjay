## 1. Papers 데이터셋 필터링 ✅

**입력 파일**: `unified_output/paper_dataset_enriched_s2_checkpoint_4850.jsonl`
**출력 파일**: `kidney_filtered/papers_kidney.jsonl`
**상태**: ✅ 완료

### 필터링 기준
- **3단계 필터링 로직**:
  1. 고특이도 용어 (dialysis, nephropathy, glomerulonephritis 등) → 자동 포함
  2. 핵심 신장 용어 (kidney, renal, nephro, 신장, 콩팥, 사구체 등) → 자동 포함
  3. 일반 용어만 있는 경우 (diabetes, hypertension 등) → 제외
- Title, Abstract, Keywords 전체 분석
- 영어: 단어 경계 기반 정규식 매칭 (`\b` word boundary)
- 한국어: 정확한 문자열 매칭

### 진행 상황
- 처리된 레코드: 4,850 / 4,850
- 필터링된 레코드: **1,659개** (34.2%)
- 제외된 레코드: 3,191개 (65.8%)
- 진행률: 100%

### 발견된 주요 패턴
- 고특이도 용어가 포함된 논문: 대부분 신장 관련 연구
- 핵심 용어 + 당뇨/고혈압 조합: 당뇨병성 신병증, 고혈압성 신질환 등 신장 합병증 연구
- Title에만 신장 용어가 있는 경우: Abstract에도 관련 내용이 대부분 포함

### 개선 사항
- **첫 번째 시도 (2,267개, 46.7%)**: 일반 용어 포함으로 과다 필터링
- **두 번째 시도 (제외된 샘플에서 "신" 발견)**: 단일 한국어 문자 "신"이 "정신", "신경" 등 비관련 용어와 매칭
- **최종 (1,659개, 34.2%)**: "신" 제거 후 정확도 향상

## 주요 발견 사항

### 1. 필터링 로직의 진화

#### 문제 1: 일반 용어 과다 포함 (Papers 첫 시도)
- **증상**: 2,267개 (46.7%) - 너무 많은 논문 포함
- **원인**: diabetes, hypertension 같은 일반 용어만으로도 필터링
- **해결**: 3단계 필터링 로직 도입
  - 고특이도 용어 (dialysis, nephropathy) → 자동 포함
  - 핵심 신장 용어 (kidney, renal) → 자동 포함
  - 일반 용어만 있으면 → 제외

#### 문제 2: 한국어 단일 문자 "신" 문제
- **증상**: Medical 첫 시도에서 35,754개 (84.5%) 과다 필터링
- **원인**: "신" 단일 문자가 비관련 용어와 매칭
  - 정신 (mental), 신경 (nerve), 신체 (body), 신규 (new) 등
- **해결**: "신" 제거, 다문자 용어만 사용 (신장, 콩팥, 사구체 등)
- **결과**: Medical 7,512개 (17.8%)로 정확도 향상

### 2. 용어집 품질

#### 효과적이었던 용어들
- **고특이도 영어**: dialysis, nephropathy, glomerulonephritis, CKD, ESRD
- **고특이도 한국어**: 투석, 혈액투석, 복막투석, 신증후군, 신병증
- **핵심 용어**: kidney, renal, nephro, 신장, 콩팥

#### 제외된 용어
- **단일 한국어 문자**: "신" (너무 많은 false positive)
- **일반 용어**: diabetes, hypertension (핵심 용어 없이는 제외)

### 3. 데이터셋별 특성

#### Papers (34.2% 필터링)
- 학술 논문의 전문성 덕분에 높은 정확도
- Title만 봐도 신장 관련 여부 대부분 판단 가능
- Abstract에서 추가 검증

#### Medical (17.8% 필터링)
- 일반 의학 지식과 전문 지식 혼재
- Keyword 필드가 필터링에 중요한 역할
- "신" 문제로 인한 초기 어려움

#### QA (5.0% 필터링)
- 일반 건강 질문이 대부분
- 하지만 절대 개수는 가장 많음 (112,322개)
- 대한신장학회 source와 category 기반 자동 포함이 효과적
- 88개 (대한신장학회) + 118개 (category) = 206개 자동 포함

### 4. 성능 및 확장성

#### 처리 성능
- **Papers**: 4,850개 - 즉시 완료
