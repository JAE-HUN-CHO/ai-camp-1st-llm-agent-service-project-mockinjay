1. 북마크 목록 조회:   - 마이페이지 > 북마크한 논문 메뉴 진입   - DB에서 사용자 ID로 북마크 목록 조회 (PMID, 북마크 날짜, 폴더, 메모)   - 각 PMID로 논문 메타데이터 조회 (캐시 활용 또는 PubMed API 호출)   - 논문 정보 (제목, 저자, 발행일, 초록, DOI) + 북마크 정보 결합   - 페이지네이션 (20개씩)2. 검색 및 필터링:   - 검색 키워드 입력 시 → 제목, 저자, 키워드에서 검색 (DB LIKE 쿼리 또는 전문 검색)   - 발행 연도 필터 선택 시 → 해당 연도 논문만 필터링   - 폴더 선택 시 → 해당 폴더 논문만 표시   - 정렬 조건 (최신순/오래된순) 적용3. 논문 상세 조회:   - 논문 클릭 시 → PubMed 원문 링크(https://pubmed.ncbi.nlm.nih.gov/{PMID}) 새 탭에서 열기   - 또는 앱 내 상세 페이지에서 초록, 저자, 메타데이터 표시4. 북마크 해제:   - 논문별 삭제 아이콘(휴지통) 클릭 → 확인 다이얼로그 → DB에서 북마크 삭제   - 다중 선택 모드: 체크박스로 여러 논문 선택 → "선택 삭제" 버튼 → 일괄 삭제5. 논문 메모 추가/수정:   - 논문별 메모 아이콘(📝) 클릭 → 메모 입력 모달 표시   - 메모 작성/수정 (최대 500자) → DB에 저장   - 메모가 있는 논문은 메모 아이콘에 Badge 표시6. 폴더 관리:   - 폴더 생성: "새 폴더 만들기" → 폴더명 입력 → DB에 폴더 저장   - 논문을 폴더로 이동: 논문 선택 → 드롭다운에서 폴더 선택 → 이동   - 폴더 수정/삭제: 폴더명 변경, 폴더 삭제 (폴더 내 논문은 "미분류"로 이동)7. 내보내기:   - "내보내기" 버튼 클릭 → 형식 선택 (CSV/BibTeX)   - CSV: PMID, 제목, 저자, 발행일, DOI, 북마크 날짜, 폴더, 메모   - BibTeX: 논문 인용 형식으로 생성   - 파일 다운로드8. 공유:   - 논문 선택 → "공유" 버튼 클릭   - 링크 공유: 클립보드에 논문 URL 복사
1. 북마크 목록 화면:   - 논문 카드 형태로 표시: 제목(굵게), 저자, 발행일, PMID, 북마크 날짜   - 각 카드 우측: 북마크 해제 아이콘(⭐→☆), 메모 아이콘(📝), 더보기 메뉴(⋮)   - 상단: 검색바, 필터(발행 연도, 폴더), 정렬(최신순/오래된순)   - 하단: 페이지네이션2. 검색 결과:   - 검색 키워드 하이라이트   - "N개의 논문이 검색되었습니다" 메시지   - 검색 결과 없으면 "검색 결과가 없습니다" + 전체 목록 보기 버튼3. 논문 상세 모달 (선택):   - 제목, 저자, 발행일, DOI, 초록   - "PubMed에서 보기" 버튼 (원문 링크)   - "메모" 섹션 (작성/수정)   - "폴더 이동" 드롭다운4. 메모 입력 모달:   - 텍스트 영역 (최대 500자, 글자 수 카운터)   - "저장" / "취소" 버튼   - 저장 시 "메모가 저장되었습니다" 토스트 메시지5. 폴더 관리 화면:   - 좌측: 폴더 리스트 (전체, 관심 논문, 읽은 논문, 나중에 읽을 논문, + 새 폴더)   - 폴더 클릭 시 해당 폴더 논문만 표시   - 폴더별 논문 개수 표시6. 다중 선택 모드:   - 체크박스 표시   - 상단에 선택된 논문 개수 표시   - "선택 삭제", "폴더 이동", "공유" 버튼 활성화7. 내보내기 다운로드:   - 파일 다운로드 (bookmarks_YYYYMMDD.csv 또는 bookmarks_YYYYMMDD.bib)8. 공유 완료 메시지:   - "링크가 클립보드에 복사되었습니다" 또는 토스트 메시지
