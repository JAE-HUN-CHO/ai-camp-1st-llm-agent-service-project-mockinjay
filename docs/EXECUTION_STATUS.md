## Section 1: 전체 요약 (Summary)

### 📊 프로젝트 목적

CareGuide는 만성콩팥병(CKD) 환자, 일반인, 연구자를 대상으로 AI 기반 의료 정보 제공, 영양 관리(NutriCoach), 커뮤니티, 연구 트렌드 분석을 통합한 종합 케어 플랫폼입니다.

**핵심 가치**:
- 🎯 3가지 페르소나 맞춤형 서비스 (일반인, 질환자, 연구자)
- 🤖 AI 챗봇 + PubMed RAG 연동
- 🍽️ CKD 단계별 맞춤 영양 관리
- 🏥 False Negative 방지 중심 의료 안전성 설계
- 📊 연구자 대시보드 및 트렌드 시각화
