🔬 논문 검색 (RESEARCH - 연구자용)

발화 예시:
• "CKD 조기진단 관련 최신 논문"
• "이 3개 논문의 차이점 비교"
• "바이오마커 연구 트렌드는?"

처리 흐름:
→ PubMed 검색 또는 내부 DB 검색
→ RAG 기반 논문 요약
→ 다중 논문 비교 분석
→ 트렌드 시각화 (시계열, 네트워크)
🎯 의료 정보 질의 (MEDICAL_INFO)

발화 예시:
• "크레아티닌 2.1은 위험한가요?"
• "CKD 3기에서 뭘 해야 하나요?"
• "투석 준비 뭐 해야 해요?", "투석 부작용은?"

처리 흐름:
→ 사용자 프로필(일반인, 질환자, 전문가) 확인
→ 맞춤형 답변 생성 + 출처 제공
-일반인: 기초 의학, 국내 의료 정보
-질환자: 기초 의학, 국내 의료 정보
 + “관련 연구 정보 원하세요?" → YES 시 PubMed 논문 연동
-전문가: 바로 PubMed 논문 검색
정책적으로 논문 검색을
추천하지 않도록 프롬프트
⚠️ 의학적 판단 차단- 진단/처방/복약/병원 제시 (POLICY)

발화 예시:
• “지금 배가 너무 아픈데 이 증상은 뭔가요?"
• "이 약 먹어도 되나요?"
• "수술이 필요한가요?"

처리 흐름:
→ 의도 분류: SYMPTOM / PRESCRIPTION
→ 자동 응답: "의사 검진이 필요합니다”
→ 응급 시: “가까운 병원 정보 안내”
발화 예시:
“신장 이식 수술  잘하는 병원이 어디야?”
“강원도에서 신장 이식할 수 있는 병원이 어디야 ?”
“미국가서 신장 수술 받을 수 있어 ?"

🏥 복지 문의 (WELFARE_INFO) ★신규

발화: "경기도 사는데 서울 병원 다녀요, 이동 복지는 어디 신청?",
      "복지 혜택 뭐 받을 수 있어요?", "장애등급 신청 방법?"
처리:
→ 1단계: 사용자 거주지/병원 위치 확인 질문
→ 2단계: 가능한 복지 목록 먼저 나열
   • 중앙정부: 복지로(bokjiro.go.kr) 신청 가능 항목
   • 거주 지자체: 경기도 복지 포털 신청 항목
   • 병원 소재지: 서울시 의료비 지원 사업
   • 국민건강보험공단: 본인부담금 상한제, 산정특례
→ 3단계: 친절한 질문 유도
   "어떤 복지가 가장 필요하신가요?"
   "현재 받고 계신 복지가 있으신가요?"
→ 4단계: 맞춤 안내 + 신청 방법 + 필요 서류

복지 카테고리:
• 의료비 지원 (본인부담금, 산정특례)
• 이동 지원 (장애인콜택시, 교통비)
• 간병 지원 (간병인, 요양보호사)
• 생활 지원 (생계급여, 주거급여)
• 장애 등급 (장애인복지카드)
