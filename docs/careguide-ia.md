## 프로젝트 개요

CareGuide는 일반인, CKD 환자, 연구자를 위한 종합 케어 플랫폼입니다.

**핵심 기능:**
- AI 챗봇 기반 의료정보 제공 (Multi-Agent)
- PubMed 논문 검색 및 RAG 분석
- 식단 관리 및 영양 추적 (NutriCoach)
- 커뮤니티 및 연구자 대시보드

## 🔐 보안 및 정책

### False Negative 방지 전략

| 정책 | 설명 |
|------|------|
| **증상 보고 시 절대 안심 금지** | "괜찮습니다", "정상입니다" 답변 차단 |
| **응급 키워드 감지** | 흉통, 호흡곤란 등 → 즉시 119 안내 |
| **신뢰도 점수 기반** | Confidence < 0.7 → 병원 방문 권장 |
| **멀티턴 검증** | 증상 지속 기간, 강도, 동반 증상 3회 확인 |
| **Disclaimer 고정 표시** | "본 답변은 진단이 아니며 참고용입니다" |
